# mental-health-project
Mental Health Data Analysis &amp; Prediction using ML

## 📊 Project Overview
This project focuses on analyzing mental health data and building machine learning models to identify patterns and make predictions.

## 🚀 Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning Models (Linear & Logistic Regression)

## 🛠 Technologies Used
- Python
- Pandas, NumPy
- Matplotlib
- Scikit-learn

## 📌 Outcome
Gained insights from data and built predictive models for better decision-making.
